- [ ] Preemptive scheduler
- [ ] Clear seperation of kernelspace and userland
- [ ] Fat32 support
- [ ] Custom RAMFS
- [ ] DE complete with OWM (OwOS Window Manager), compositor and usable programs
### Userspace programs:

  - [ ] BEFO: **B**asic **E**ditor **F**or **O**wOS (edit and create files)
